Tính năng

Một chỗ để điều phối nhiều agent

Giao diện giống Claude ở giữa, file và Git giống VS Code bên phải. Mọi thứ chạy trên máy bạn, bằng chính các CLI bạn đã đăng nhập.

Chat với nhiều agent

Đổi qua lại Claude, Codex, Antigravity giữa cuộc trò chuyện; agent sau tự biết agent trước đã làm gì.

Pipeline Plan → Review → Code → Test

Sơ đồ kéo thả kiểu n8n, dừng chờ duyệt, Review chấm ĐẠT hoặc CHƯA ĐẠT rồi tự gửi góp ý lại cho bước trước.

Usage 5 giờ và tuần

Xem quota còn lại của Claude, Codex, Antigravity; bấm dùng lượt reset của Codex ngay trong app.

Git và nhiều repo

Mở một thư mục cha là tự tìm các repo con; commit, đổi nhánh, push, viết commit message bằng AI.

Báo lỗi code

Chạy TypeScript, ESLint, Biome, Ruff của project; tô đỏ file lỗi, gạch chân trong editor, một nút gửi cho agent sửa.

Terminal và Preview

Terminal ngay trong app, chạy npm run dev là tự mở tab Preview để xem trang đang làm.

Gõ / để dùng lệnh và skill

Hiện skill và lệnh cài trong project của từng CLI, chọn là dùng, không cần nhớ tên.

Kéo thả file, dán ảnh

Đính kèm file và ảnh chụp màn hình vào chat; bấm tên file trong câu trả lời là mở đúng dòng.

Bắt đầu

Ba bước là dùng được

AgentDesk không chứa model nào, nó điều khiển các CLI chính chủ trên máy bạn, dùng đúng tài khoản và quota của bạn.

Cài CLI bạn muốn dùng

npm i -g @anthropic-ai/claude-code rồi claude để đăng nhập. Codex: npm i -g @openai/codex, codex login. Cài một CLI cũng được.

Tải và cài AgentDesk

macOS: mở file .dmg, kéo vào Applications. Windows: chạy file cài, không cần quyền admin. Node đã có sẵn bên trong.

Chọn project và giao việc

Mở thư mục code, chọn agent và model, gõ yêu cầu. Hoặc chạy cả pipeline và duyệt từng bước.

Lưu ý

Lần đầu mở app

App chưa ký bằng chứng chỉ trả phí nên hệ điều hành sẽ hỏi lại một lần.

macOS

Nếu báo không mở được: vào System Settings → Privacy & Security, bấm Open Anyway. Hoặc chạy xattr -dr com.apple.quarantine /Applications/AgentDesk.app.

Windows

SmartScreen hiện "Windows protected your PC": bấm More info → Run anyway. Cửa sổ app mở bằng Microsoft Edge ở chế độ ứng dụng.

Dữ liệu ở đâu?

Chỉ trên máy bạn, trong ~/.agentdesk. App không gửi code hay cuộc trò chuyện đi đâu ngoài các CLI bạn chọn.

Cập nhật

Có bản mới, mục Cập nhật ở cuối sidebar chuyển màu cam; bấm để tải và cài đè, dữ liệu giữ nguyên.
